# 논문과 공개 코드의 용어 대응

첨부 논문 「한국 행정 환경을 고려한 N2SF 분류 체계: C/S/O 데이터셋 및 RAG 기반 분류모델 연구」의 7쪽, Ⅳ.3. 분류 모델의 표 3과 소제목 2)를 기준으로 표시 명칭을 맞추었다. 논문 PDF 자체는 이 패키지에 포함하지 않는다.

| 기존 설명 명칭 | 논문에 맞춘 표시 명칭 | 의미 | 보존하는 내부 식별자 |
|---|---|---|---|
| 통합 분류기준 v3 / 통합 기준 v3 | **CSO-RAG 판정 기준** | 법령 원문, 기관별 공식 세부기준, 프로젝트 판정 지침과 N2SF 등급 매핑 | `v3-confirmed-20261011-02` |
| 프로토콜 v3.2 / 입력·판정 실행 프로토콜 | **RAG 기반 문단별 등급 판정** | 입력 구성, 사례 검색, 등급과 근거 생성, 자동 검증 및 문서 집계의 절차 | `v3.2-selective-criteria-20261012-03` |
| 검증 r1 | **자동 검증 개정본 r1** | 사유 속 ID 재표기 누락을 필수 실패에서 진단으로 분리한 검증 | `v3.2-validation-r1-20261015-01` |

논문 소제목의 정확한 표현은 “RAG 기반 문단별 등급 판정”이다. 본문에서 절차임을 설명할 때에는 “문단별 판정 절차”로 줄여 쓸 수 있다. “RAG 기반 문단별 판정 절차”는 의미가 통하는 설명이지만 소제목 자체를 인용할 때에는 논문의 표현을 사용한다.

## 변경 범위

- README와 재현 안내의 표시 명칭에 더해 기준 참조본의 제목과 현재 실행 메타데이터를 정리했다. 명칭 통일로 판정 기준의 조건이나 모델 입력 문구가 바뀐 것은 아니다.
- 생성모델에 실제 전달하는 기준 문자열과 시스템 프롬프트, JSON 스키마 및 생성 문법 코드는 변경하지 않았다. 참조 JSON의 비입력 메타데이터 14개 version 표기와 최상단 표시 정보만 정리했다.
- `classification_criteria_version`, `protocol_version`, `validation_revision` 등 실제 실행 설정의 필드와 버전 ID는 유지한다. 참조본의 오래된 execution_protocol_version 메타데이터만 현재 설정과 같은 v3.2로 정리했으며, 변경한 공개 파일의 해시는 새로 기록하고 원래 실험 해시는 보존한다.
- 과거 검토와 출처 기록은 당시의 명칭으로 보존한다. 원문 전사와 기존 실험 입력 안에 있는 단어를 사후 변경하지 않는다.
- 결과표와 실제 모델 출력 및 이미지도 변경하지 않았다. 추가 추론이나 모델 다운로드는 수행하지 않았다.

따라서 모델 입력 파일에서 “프로토콜 v3.2”라는 과거 명칭이 보이더라도 다른 설정을 사용한 것으로 해석하지 않는다. 공개 설명에는 논문 용어를 쓰고, 내부 파일에는 실제 실험에 사용한 식별자를 남긴 것이다.


## 현재 실행 버전과 과거 기록

- 현재 실행: `v3.2-selective-criteria-20261012-03`.
- 현재 자동 검증: `v3.2-validation-r1-20261015-01`.
- v3.1 표기: 계승한 출력 구조·생성 문법 또는 과거 기준 승인 기록을 가리킨다. 현재 전체 실행 절차가 v3.1이라는 뜻이 아니다.
- [현재 기준 참조본](../assets/criteria_reference_v3/integrated_criteria_v3.json)의 `execution_protocol_version`은 현재 실행을 설명하는 메타데이터다. 실제 실행 설정은 `config.example.json`을 사용한다.
- [변경 전 참조본](../provenance/history/integrated_criteria_v3_at_69f6c22.json)은 원래 바이트로 보존했다. 당시 `activation`과 `differences_from_v2`, 초안 version 및 모델 미실행 상태는 이 과거 기록에서 확인한다.

모델 입력 문자열에 남아 있는 이전 버전 언급은 실험 당시 고정된 문구다. 이를 현재 표시명에 맞춰 사후 치환하지 않았다. 참조 메타데이터를 정리한 뒤에도 저장된 최종 요청과 동일한 입력 문자열이 생성되는지를 별도로 확인했다.
