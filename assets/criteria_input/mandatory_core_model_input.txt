나. 위법ㆍ부당한 사업활동으로부터 국민의 재산 또는 생활을 보호하기 위하여 공개할 필요가 있는 정보

[항상 제공: 프로젝트 판정·처리 지침]
P-SCOPE: 제공된 문단 경계를 유지하고 대상 문단만 판정한다. 다른 문단·검색 사례의 등급을 그대로 전파하지 않는다.
P-CONDITION: 주제어가 아니라 정보의 성격, 공개 위해의 인과관계·정도, 각 호의 예외와 공개 요건을 확인한다. 확인한 조건과 추정·가정을 구분한다.
P-INSTITUTION: 기관 예시는 해당 기관·부서·업무 범위와 실제 정보 성격을 함께 확인한다. 보안 업무 예시를 일반 기술 설명에 자동 적용하지 않는다.
P-FOI4-HARM-OR: 제4호의 관련 업무·정보에 해당하는지 먼저 확인한다. 공개로 그 직무수행을 현저히 곤란하게 하거나 형사피고인의 공정한 재판을 받을 권리를 침해한다고 인정할 만한 상당한 이유가 있는지 원문과 필요한 문맥으로 확인한다. 두 위해 중 적어도 하나를 뒷받침하면 되며 두 위해를 모두 필수로 요구하지 않는다. 관련 업무라는 사실이나 진행 중이라는 사실만으로 위해 조건을 충족했다고 보지 않는다. N2SF 표2-8의 축약 전사 “및”은 그대로 보존하지만 이를 두 위해의 동시 충족 요건으로 해석하지 않는다.
P-TIME: 날짜 차이만으로 사건 종료를 추론하지 않는다. 종료 여부 불명확 시 진행 중으로 가정하는 기존 프로젝트 조건을 유지하고 “진행 중 가정”을 명시한다. 명시적 종료 사실은 존중한다. 진행 중이라는 사실·가정만으로 제4호 충족을 인정하지 않는다.
P-CONTEXT: 실제로 제공된 평가 원문·문맥만 사용한다. 지시어·인물·사건·단계 등 대상과 문맥의 연결을 설명하고 출처 문단 및 E ID를 명시한다. 같은 주제라는 이유로 다른 문단의 보호등급을 빌리지 않는다.
P-EVIDENCE: 충족을 주장하는 각 기준에 최소한의 충분한 근거 E ID와 충족 사유를 연결한다. 대상 문단 E ID를 적어도 하나 포함한다. 필요한 복수 근거·복수 기준을 허용한다. 동일 기준·근거 ID를 반복하지 않는다. 검색 영역 R은 평가 원문 근거로 선택하지 않는다.
P-O: O의 C/S 조건 비해당 경로는 유지한다. 충분한 원문과 실제 제공 문맥을 검토한 비해당 판단에는 가상의 적용 기준·근거를 강제하지 않는다. 정보 부족은 O의 근거가 아니다. 실제 기관의 비공개 유지 상태·기간 경과에 따른 필요성 소멸을 확인할 수 없으므로 제9조제2항 및 비공개 필요성 소멸 경로는 이번 판정·평가에 사용하지 않는다. 날짜만으로 공개 전환을 판단하지 않는다. 법령상 공개 요건 충족 경로는 소멸 경로와 다른 개념이며, 독립 출력 표현은 현 프로토콜 v3.1에서 미지원이므로 자동 추가하지 않는다.
P-UNCERTAINTY: 등급 제안은 가능하나 해석상 불확실하면 제안 등급과 모델 검토 요청을 분리한다. 핵심 조건이 부족해 판정 자체가 불가능하면 미분류로 남긴다. 검토 필요·미분류를 자동 O로 바꾸지 않는다.
P-AGGREGATION: 문서의 모든 문단 판정이 완료되면 C>S>O 최고 등급으로 집계한다. 미분류 문단이 있으면 불완전 상태와 유효 문단의 부분 제안을 분리한다. 이 집계 방식은 프로젝트 규칙이다.
P-VALIDATION: Python Unicode 문자 위치·끝 위치 포함 방식을 유지한다. 실제 제공 E ID·출처·인용·위치를 검사한다. 기술 검증 통과와 기준 적용·사유의 의미상 타당성을 구분한다. 제안 등급과 자동 검증 상태·모델 검토 요청을 별도 저장한다.
P-NO-GOLD: 평가 정답 등급·근거·정답 적용 기준·정답 사유·개별 수정 예시는 검색·생성·코드 검증 입력에서 제외한다. 허용된 검색용 사례의 라벨·근거는 별도 R 영역에만 제공한다. 공통 기준에 개별 평가 사례를 포함하지 않는다.
P-ALIAS: 원래 ID를 보존한다. 조항·정의·조건을 대조하여 동일 의미가 확인된 별칭만 대응시킨다. 조문 번호가 같다는 사실만으로 판정 조건의 동등성이나 해당 라벨 타당성을 인정하지 않는다.
P-PRIVACY: 성명·주민번호·주소 등의 존재만으로 C를 적용하지 않는다. 제6호의 사생활 침해 조건과 예외를 확인하며, 제3호 등 별도의 C 조건을 주장하려면 해당 위해를 원문·문맥으로 뒷받침한다.
P-LOG: 로그·임시백업의 실제 내용을 대상으로 N2SF 매핑을 참고한다. 단어를 언급하는 설명문에 S를 자동 적용하지 않고 별도의 C 조건도 검토한다.

[O 경로 및 연구 범위]
O_public: C/S 조건 비해당을 충분한 원문·제공 문맥으로 판단; 정보 부족과 구분. 선택된 세부항목이 없다는 이유만으로 O를 판정하지 않는다.
O_release: LAW-FOI-9-2 및 비공개 필요성 소멸 경로는 기준 v3에 따라 연구 판정 범위에서 제외. N2SF 원문의 해당 경로는 참조본에만 보존. 현 출력 형식의 non_disclosure_expired/N2SF-O-RELEASED를 이번 판정에 사용하지 않는다.
legal_public_requirements: 법령상 공개 요건과 기간 경과에 따른 소멸은 구분한다. 제6·7호 등의 법률 예외는 원문대로 검토하며 독립 O 경로 출력 기능은 추가하지 않는다.
N2SF_table_and: 표의 및 전사를 보존하며 제4호 위해는 법령의 하거나대로 두 위해 중 하나 이상; 두 위해 모두 필수 아님.
선택 한계: 선택은 원문 표현에 기반한 관련 후보 선별이며 법적 적용 확인이 아니다. 선택되지 않은 항목은 비해당으로 검증된 항목이 아니다. 전체 기준 제1~8호 조건·예외를 계속 검토한다. 기관 항목을 다른 기관에 자동 적용하지 않는다.

[기관 범위 공통 안내]
행정안전부의 공통업무 또는 해당 부서 고유업무에 적용. 타 기관 정보는 업무 대응과 법적 요건을 따로 확인하며 자동 전용하지 않음.
기관 항목은 관련 후보일 뿐 대상 문서에 적용된 사실로 확인되지 않았다. 기관·부서·업무 성격과 법적 조건을 따로 확인한다.
